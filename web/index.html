    How it works

    Muse Spark 1.3 reads the drawing into a structured part spec: features and named parameters, never free-form CAD code. Our own compiler builds the solid with CadQuery, deterministically. Then Talos checks the part against your drawing: every dimension it read is measured on the solid, SAM 3.1 outlines each view of the drawing and compares it with the part's silhouette, every number is read a second time on its own, and a separate critic call compares the drawing with a drawing of the part. Whatever is off goes back to the model until the checks pass. Sliders and spoken edits (Muse Voice Transcribe) change the spec and rebuild it without asking a model to redraw anything.

    Honest limits

    • Prismatic and revolved parts: plates, brackets, blocks, bushings, enclosures, pockets, holes, slots. No freeform surfaces, no assemblies.
    • The drawing needs written dimensions; Talos never guesses the scale.
    • On the 24-image benchmark the live model's first read is already right on 23; the loop's value is catching the rest without making correct reads worse. A misreading every check shares (two close numbers swapped) can still get through.
    • Handwriting: 13 of 16 hand sketches right on the first read, 14 after confirming the flagged numbers.
